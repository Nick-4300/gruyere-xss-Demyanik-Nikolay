## 📌 Цель работы

Научиться использовать инструмент **Scapy** для анализа сетевого трафика и эксплуатации уязвимостей **cross-site scripting (XSS)** на учебном сайте **Google Gruyere**.

В ходе работы требовалось:

- настроить Scapy для перехвата HTTP-трафика;
- проанализировать HTTP-запросы и ответы (включая сжатые gzip);
- провести рекон-анализ Google Gruyere и найти точки внедрения XSS;
- проэксплуатировать найденные уязвимости с параллельным перехватом трафика;
- сохранить трафик в `.pcap` и проанализировать его скриптом;
- описать изменения в трафике во время XSS-атаки.
